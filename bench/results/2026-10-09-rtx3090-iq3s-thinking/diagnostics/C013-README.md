Followed docs/MMVQ_IL_TABLE.md. The build script compiles the unchanged existing mmvq_il_parity.cpp test with /O2 /MT and links the candidate build-cuda86 GPU/core libraries plus CUDA13.3. No model was resident during two separate --bench --emit-table sweeps. Both ended OK: every tested T2-4 row choice1/2/4 and table output matched the plain kernel bit for bit with finite outputs. The fixture performs200 warm-up calls and200 timed calls per choice, cycling weight copies beyond L2. It reports per-call averages, not an all-run served median; sweep-to-sweep timing differences remain visible.

select-il-table.py is stricter than the upstream emitter: every measured shape of a class in both sweeps must improve on its currently shipped choice by at least3%. Unmeasured and uncertain cells retain the shipped table. C013-il-selection.json retains every selected comparison and the full STRATA_MMVQ_IL_ROWS value. Nine cells qualified, with worst measured ratios0.800-0.967. No model/prompt information selects the table.

To reproduce, copy these sources/logs to <STRATA_ROOT>/local-setup/target-80, adjust the compiler/toolkit paths in build-mmvq-il-test.cmd, run the unchanged upstream test twice with --bench --emit-table, then run the selection script. The script expects B008-promoted-control.json in that local folder when writing a runtime candidate; reconstruct it from the report's normalized baseline identity or retain your own unchanged control.
